> 이 글의 숫자는 직접 만든 특징 추출 스크립트의 출력 표를 다시 집계한 것입니다. pcap 원본이나 샘플은 공유하지 않습니다.

## 한 줄 요약

2017년 공개 랜섬웨어 pcap 287개에서 **내부 확산(SMB·RDP·ARP 스캔) 신호는 하나도 없었다.** 전부 "PC 한 대가 감염되는 과정"이었고, 가장 흔한 신호는 **랜덤처럼 보이는 URI(40%)**, 그다음이 **DGA처럼 보이는 도메인(29%)**, **Cerber식 UDP 버스트(25%)**였다.

## 데이터

- 출처: malware-traffic-analysis.net의 2017년 게시글에 첨부된 압축 파일 130개에서 중복을 제외한 **고유 pcap 287개**.
- 라벨: 파일 이름과 게시글 제목 기준의 패밀리 이름입니다. 정확한 판정이 아닙니다.
- 패킷 수: 중앙값 422, 최대 69,298 (일부 pcap은 패킷이 거의 없었습니다).

| 패밀리 | pcap 수 |
|---|---:|
| Cerber | 138 |
| 기타·미분류 | 50 |
| Locky | 31 |
| GlobeImposter | 20 |
| Spora | 12 |
| Jaff | 10 |
| CryptoMix | 7 |
| Sage | 7 |

## 방법

- `tshark`로 pcap을 읽고 pcap마다 **특징을 세는** 스크립트를 썼습니다. 응답 본문은 저장하지 않고 스트리밍으로 처리했습니다.
- 각 신호는 "그 pcap에서 한 번이라도 보였는가"로 셉니다. 아래는 **탐지 기준이 아니라 관찰 빈도**입니다.

## 결과 1: 내부 확산 신호가 없다

| 항목 | pcap 수 |
|---|---:|
| SMB 대상 스캔 | 0 |
| RDP 대상 스캔 | 0 |
| ARP 스윕 | 0 |
| 내부 확산 신호로 표시된 pcap | **0 / 287** |

이 캡처들은 전부 **한 대의 감염 체인**(메일·웹 → 다운로드 → 감염)입니다. 공개 pcap으로는 "한 번 감염된 뒤 내부로 퍼지는 모습"을 볼 수 없다는 뜻입니다.

## 결과 2: 감염 체인에서 보인 신호

| 신호 | 의미 | pcap | 비율 |
|---|---|---:|---:|
| 랜덤 URI 요청 | 경로가 무작위 문자열로 보이는 HTTP 요청 | 116 | 40% |
| DGA 유사 도메인 | 사람이 읽기 어려운 도메인 이름 | 83 | 29% |
| UDP 버스트 | 한 출발지가 같은 UDP 포트로 외부 20개 이상 IP에 전송 | 73 | 25% |
| 바이너리 다운로드 응답 | `octet-stream`·`x-msdownload` 등 | 71 | 25% |
| IP 직접 접속 | `Host`가 IP 주소 | 52 | 18% |
| SWF 응답 | 플래시 익스플로잇 응답 | 46 | 16% |
| 본문이 PE | 응답 본문이 `MZ`로 시작 | 40 | 14% |
| 대용량 고엔트로피 응답 | 압축·암호화처럼 보이는 큰 응답 | 32 | 11% |
| 익스플로잇 킷 체인 | SWF 뒤에 페이로드 | 28 | 10% |
| Tor 게이트웨이 이름 | `onion` 계열 이름 조회 | 16 | 6% |
| IP 조회 서비스 | 공인 IP 확인 서비스 사용 | 9 | 3% |

비교를 위해 하나 더 있습니다. **"의심스러운 TLD"(`.top`, `.xyz`, `.info` 등)가 나온 pcap은 202개(70%)**였습니다. 이렇게 흔한 신호는 구분 기준으로 거의 쓸모가 없다는 반례입니다.

위 11개 신호 중 **하나라도** 보인 pcap은 185개(64%), **하나도 없는** pcap은 102개(36%)였습니다. 가장 약한 신호(랜덤 URI 등)까지 포함한 숫자입니다.

## 결과 3: 패밀리마다 모양이 다르다

| 패밀리 | n | UDP 버스트 | 다운로드류 | 랜덤 URI | DGA류 | Tor |
|---|---:|---:|---:|---:|---:|---:|
| Cerber | 138 | **71** | 42 | 71 | 66 | 0 |
| Locky | 31 | 0 | **22** | 5 | 0 | 0 |
| GlobeImposter | 20 | 0 | 3 | 4 | 7 | **14** |
| Spora | 12 | 0 | 6 | 1 | 0 | 0 |
| Jaff | 10 | 0 | 0 | 1 | 1 | 0 |
| CryptoMix | 7 | 0 | 5 | 7 | 0 | 0 |
| Sage | 7 | 2 | 0 | 0 | 4 | 0 |

- **Cerber**는 138개 중 71개에서 외부 다수 IP로 가는 UDP 버스트가 보였습니다(가장 눈에 띄는 특징).
- **Locky**는 UDP 버스트가 없고 31개 중 22개에서 다운로드 신호가 보였습니다.
- **GlobeImposter**는 20개 중 14개에서 Tor 관련 이름이 보였습니다.
- **Jaff**(10개)는 거의 신호가 없었습니다.

## 한계

- 신호는 **휴리스틱 관찰 빈도**입니다. 정상 브라우징 캡처와 비교하지 않았으므로, 이 신호들이 얼마나 정상 트래픽에도 나오는지(오탐률)는 모릅니다. 탐지 기준으로 쓰면 안 됩니다.
- 2017년 한 해의 공개 캡처이고, 대부분 익스플로잇 킷·메일 기반 감염 체인입니다. 요즘 랜섬웨어와 다릅니다.
- 라벨은 파일명 기준이라 틀릴 수 있고, 기타·미분류가 50개(17%)입니다.
- 신호 정의의 임계치(예: UDP 20개 이상)는 제가 정한 값입니다.
- 이 표는 집계 결과를 다시 센 것이고, 이번에 pcap 전체를 처음부터 다시 분석한 것은 아닙니다.

## 정리

- 공개 랜섬웨어 pcap은 **한 대 감염 체인** 위주라서 내부 확산을 보는 데는 쓸 수 없다.
- 패밀리별 모양은 뚜렷하다(Cerber는 UDP, Locky는 다운로드, GlobeImposter는 Tor).
- 흔한 신호(랜덤 URI, 의심 TLD)는 단독으로는 의미가 약하다.
- 요즘 랜섬웨어는 공개 pcap 자체가 드뭅니다. 그래서 직접 격리 랩에서 돌려 본 기록을 따로 남기고 있습니다. → [LockBit 5.0을 격리 랩에서 돌렸더니 pcap이 비어 있었다](/ko/posts/lockbit5-sandbox/)
