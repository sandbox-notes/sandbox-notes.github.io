## 이 블로그는

격리된 랩에서 악성코드를 직접 실행해 보고, **무엇을 확인했고 무엇은 확인하지 못했는지**를 그대로 기록하는 곳입니다. 보안 전문가가 되는 과정을 공개적으로 쌓아 가는 학습 기록이기도 합니다.

## 무엇을 다루나

- **랩 구축**: VMware 격리망, REMnux, FlareVM, INetSim 같은 분석 환경과 막혔던 지점들
- **샘플 분석**: 네트워크 캡처, 로컬 동작, 공개 분석과의 대조
- **삽질 기록**: 증상, 원인, 해결을 표로 정리한 트러블슈팅
- **탐지와 방어**: 분석 결과를 IOC와 탐지 규칙으로 연결하는 연습
- **일상**: 공부하며 지내는 이야기. 분석 글과 카테고리를 나누어 둡니다.

## 글을 쓰는 원칙

1. **확인한 것과 추정을 구분합니다.** 직접 관찰한 내용과 공개 자료에서 가져온 내용을 나누어 씁니다.
2. **샘플 파일은 공유하지 않습니다.** 해시와 공개 분석 링크만 남깁니다.
3. **IOC는 변형해서 표기합니다.** 도메인과 주소는 `[.]` 같은 방식으로 적습니다.
4. **개인 식별 정보를 가립니다.** 호스트명, 사용자명, 경로는 공개 전에 지웁니다.
5. **한계를 숨기지 않습니다.** 환경이 달랐다면 결과도 달랐을 수 있다는 점을 적습니다.

## 분석 환경

- 하이퍼바이저: VMware Workstation
- 실행 환경: FlareVM (Windows)
- 가짜 인터넷과 캡처: REMnux (INetSim, dnsmasq, tcpdump)
- 망 구성: 호스트와 외부 인터넷에서 분리한 전용 가상 네트워크, 실행 전 스냅샷

## 운영자

샌드박스 노트 운영자입니다. 보안 전문가를 목표로 악성코드 분석을 공부하고 있으며, 랩에서 직접 실험한 내용을 기록합니다.

공부하면서 막혔던 지점과 해결 과정을 숨기지 않고 남기는 것을 목표로 합니다.

## 면책

이 블로그의 내용은 교육과 연구 목적입니다. 개인의 의견이며 소속 조직의 입장이 아닙니다. 설명한 기법을 허가 없이 타인의 시스템에 사용하지 마세요. 분석 중 발견한 오류가 있다면 알려 주시면 확인 후 수정하겠습니다.
